#  StudyLink 2.0
### Student Learning Management System

**StudyLink 2.0** is a modern, responsive, browser-based Learning Management System (LMS) designed to simplify academic management and improve communication between students and teachers.

The platform provides a centralized interface for managing classes, assignments, learning resources, announcements, grades, and weekly timetables.

With its redesigned interface, StudyLink 2.0 offers two elegant themes: **Lavender Studio** and **Midnight Academia**.

##  Features

### Student Dashboard
- Personalized student dashboard
- Join and access classes
- View and submit assignments
- Check grades and feedback
- Access educational resources
- View announcements
- Check weekly class timetables

### Teacher Dashboard
- Create and manage classes
- Create assignments and review submissions
- Upload assignment attachments
- Evaluate student submissions
- Share learning resources
- Publish class announcements
- Create and manage weekly timetables

###  Weekly Timetable
- Organized Monday-to-Saturday schedule
- Teacher-controlled timetable management
- Read-only timetable access for students
- Today's classes displayed on the dashboard

###  Dual Theme Interface

** Lavender Studio (Light Mode)**
- Soft lavender accents
- Clean, minimal interface
- Comfortable daytime reading experience

**Midnight Academia (Dark Mode)**
- Deep navy and charcoal backgrounds
- Elegant lavender highlights
- Comfortable low-light interface

Theme preferences are saved automatically.

### Document Management
- Support for PDF and document attachments
- Assignment-related file handling
- Educational resource uploads
- Browser-based document storage

##  Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling and responsive design |
| JavaScript | Application logic and interactivity |
| LocalStorage | Application data and session persistence |
| IndexedDB | Browser-based file storage |
| Git & GitHub | Version control and project hosting |

StudyLink 2.0 currently operates without a dedicated backend server or external database service.
